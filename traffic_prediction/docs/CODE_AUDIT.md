年份均为 2019。训练用 EXTREME_FLAG；分析用 EXTREME_FLAG ∩ 分析时间窗口。即使不在 S1 事件窗口，也可能因 WEATHER_EXTREME_FLAG 被选入反事实。四组差异全部保留，不能把结果描述为完全同一事件口径。

其他保留事项：S1 全期阈值可能使用测试月信息；S2 bfill 使用同月后续天气；未来天气为原始观测而非已验证可部署的天气预报。窗口不跨月；重叠样本会重复历史点参与归一化；空样本目录原 Dataset 在 concatenate 处失败。模型没有严格保证反事实输出更大，方向损失只是软约束。分析空事件窗可能产生 NaN 汇总。以上均未擅自修正。

配置允许更改研究常量用于后续实验；默认配置保留原参数。更改配置后的科学结论需要重新验证。
